Логика рейтинга
Только свежие коммерческие сигналы
  • Убраны «Ногай», «Мираж» и Ramada: сами по себе текущие продажи не являются причиной попадания в радар.
  • Сумма продаж скрыта: оставлен только понятный статус — новый / не найден / можно допродать.
  • Название объекта = источник: клик открывает материал, на основании которого объект попал в рейтинг.
Что делать сейчас · 7–14 дней
  1. «Биом» / More: получить закупщика нового проекта и дату комплектации.
  2. Vertical Boutique: определить оператора и закупщика OS&E.
  3. ЮГ22: действующий клиент — использовать актуальный сезонный инфоповод для допродажи и выхода на групповую матрицу ALBA.
  4. ОКО/DoubleTree: действующий клиент — допродажа по свежему ресторанному проекту.
Правило включения

Есть свежий сигнал → есть объект в радаре.
Нет открытия, реконцепции, события или иного коммерческого повода → объект не занимает место в рейтинге.
